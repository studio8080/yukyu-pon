プライバシーポリシー

制定: 2026年10月3日

ここ企画（以下「当社」）は、「有休ポン」（以下「本サービス」）における情報の取り扱いを次のとおり定めます。

1. 入力したデータ

従業員の氏名・入社日・契約内容・休暇の取得日など、本サービスに入力・取り込みしたデータは、利用者のブラウザ内（localStorage・IndexedDB）にのみ保存され、当社のサーバーその他の外部には送信されません。当社がこれらのデータを取得・閲覧することはありません。

本サービスのページには、外部への通信を禁止する設定（Content Security Policy の connect-src 'none'）を入れています。

自動バックアップ機能を使う場合、利用者が選んだ利用者自身の端末上のファイルに保存します。バックアップのファイルには個人情報が含まれるため、保管・共有には注意してください。

2. ライセンスキー

有料プランのライセンスキーはブラウザ内で検証し、検証のための通信は行いません。購入時に決済事業者（Stripe）を通じて受け取る氏名・メールアドレス等は、ライセンスキーの送付、問い合わせへの対応、法令にもとづく記録のために利用します（有料プランの提供開始後）。

3. アクセス解析・広告

本サービスは、アクセス解析ツール、広告、Cookie による追跡を使用していません。

4. ホスティング事業者による記録

本サービスは GitHub Pages（GitHub, Inc.）で配信しています。ページを読み込む際、IP アドレス等のアクセス記録が同社のサーバーに残る場合があります（同社のプライバシーポリシーにもとづき取り扱われます）。入力したデータはこの通信に含まれません。

5. お問い合わせ

本ポリシーに関するお問い合わせは、studio@kokokikaku.com までご連絡ください。お問い合わせの際、従業員の個人情報やバックアップのファイルはお送りにならないでください。

6. 改定

本ポリシーを改定する場合は、本サービス上に掲示します。
